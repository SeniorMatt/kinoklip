Kinoklip 0.3.4-alpha.1 - the Keyframes panel moves to the left, as in DaVinci Resolve 20. Still an alpha: expect bugs, keep backups.

## Download and run (Linux x86_64)
1. Download `Kinoklip-x86_64.run`.
2. Make it executable: right-click > Properties > "Is executable", or `chmod +x Kinoklip-x86_64.run`.
3. Double-click it (or run `./Kinoklip-x86_64.run`). The first start unpacks into `~/.cache/kinoklip`; later starts are fast.

Needs: x86_64 Linux, OpenGL 3.3, `zstd` + `tar` (or `bsdtar`). Wayland and X11. `kinoklip-x86_64.tar.zst` is the same app as a portable folder; `SHA256SUMS.txt` has checksums.

## Changed
- The **Keyframes** button is now in the left group of the toolbar (after Edit Index), and the docked Keyframes panel opens in the left column together with the Media Pool, Effects and Edit Index, above the timeline. Opening it gives it about half of the column's height and widens the column to about a third of the window so the curve editor has room. Float / Dock and dragging its header out still work.
- Your saved Edit page layout from older versions starts from the default proportions once (which panels are shown is kept).
- Hardware decoding: a fallback to software is now logged once per file and GPU backend.
- New placeholder application icon (KDE Breeze's generic video icon) until the final Kinoklip icon is ready.
