Kinoklip 0.1.0-alpha.3 - third alpha, built from the feedback on alpha.2. Still an alpha: expect bugs, keep backups.

## Download and run (Linux x86_64)
1. Download `Kinoklip-x86_64.run`.
2. Make it executable: right-click > Properties > "Is executable", or `chmod +x Kinoklip-x86_64.run`.
3. Double-click it (or run `./Kinoklip-x86_64.run`). The first start unpacks into `~/.cache/kinoklip`; later starts are fast.

Needs: x86_64 Linux, OpenGL 3.3, `zstd` + `tar` (or `bsdtar`). Wayland and X11. `kinoklip-x86_64.tar.zst` is the same app as a portable folder; `SHA256SUMS.txt` has checksums.

## What's new since alpha.2
**Playback**
- Sharp picture while playing: playback now renders at full resolution by default, like Resolve, and drops frames instead of blurring. (alpha.2 defaulted to an over-eager "Auto" mode that fell to a quarter of the viewer size.) A saved "Auto" setting is switched to Full once.
- New Playback > Playback Resolution menu (Full / Half / Quarter / Automatic), kept in sync with the viewer's "Full Res" box and Preferences. Automatic is now cautious: Half at most, back to Full within seconds.
- Moving the playhead while playing no longer freezes: the picture follows the drag and playback continues from the new position.
- Faster: the next frame is decoded in the background; faster frame copies from Intel/AMD GPU decoding.
- `KK_PLAYBACK_STATS=1` prints playback statistics once a second (handy for bug reports).

**Editing**
- Ctrl+Shift+[ / Ctrl+Shift+] ripple-trim the clip start / end to the playhead (gap closed), as in Resolve; Shift+[ / Shift+] trim and leave a gap. Works on keyboard layouts that send { / }.
- Transitions can be clicked and selected (Inspector opens on the Transition tab), deleted, opened with a double-click, and have a right-click menu (duration, alignment, delete). The fx badge opens a clip's effects.
- A video clip with linked audio is one item in the Inspector: Video tab = picture, Audio tab = sound (alpha.2 showed the audio part, so scale couldn't be changed).
- Single / dual viewer button at the right end of the viewer header (also View > Single Viewer Mode).

**Keyframes panel**
- New Keyframes panel (interface bar, next to Mixer): parameter tree with values and keyframe buttons, dope sheet and a large curve editor with bezier handles, Linear / Smooth / Ease / Static / Flatten, normalised or shared value axis, fit, zoom and pan.
- Docks between the viewers and the timeline or floats in its own window (second monitor); synced with the timeline playhead.
- Short clips offer "Open in Keyframes Panel" instead of a cramped inline curve editor.

**Desktop integration**
- All file dialogs (Import Media, Open/Save Project, Render Location, Relink, ...) now use the desktop's own file chooser, the KDE/Dolphin dialog on Plasma. Set `KINOKLIP_FILE_DIALOG=qt` to get the old dialog.
- `--version` and `--help` work without a display.

## Known limitations
- Colour grading, compositing and audio pages are not built yet.
- Playback speed and the Intel GPU paths have not been measured on Intel Iris Xe hardware yet. If the picture ever looks wrong, start with `KINOKLIP_VAAPI_COPY=transfer` and report it.
- Inspector edits apply to one clip (or linked pair) at a time, not to all selected clips.
- 28 shortcuts are still marked "unsure" in `docs/keymap-resolve-windows.md`.
