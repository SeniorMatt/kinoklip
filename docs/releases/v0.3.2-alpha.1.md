Kinoklip 0.3.2-alpha.1 - v3 polish round 4: Normalize Audio Levels, ranged markers, EDL export, an undo history window, and a faster, lighter editor on large projects. Still an alpha: expect bugs, keep backups.

## Download and run (Linux x86_64)
1. Download `Kinoklip-x86_64.run`.
2. Make it executable: right-click > Properties > "Is executable", or `chmod +x Kinoklip-x86_64.run`.
3. Double-click it (or run `./Kinoklip-x86_64.run`). The first start unpacks into `~/.cache/kinoklip`; later starts are fast.

Needs: x86_64 Linux, OpenGL 3.3, `zstd` + `tar` (or `bsdtar`). Wayland and X11. `kinoklip-x86_64.tar.zst` is the same app as a portable folder; `SHA256SUMS.txt` has checksums.

## New
- **Normalize Audio Levels** (Clip menu and clip right-click menu): Sample Peak Program, True Peak or loudness (ITU-R BS.1770); several clips Independently or Relative to the loudest. Runs in the background with progress and Cancel; one undo step.
- **Ranged markers**: Alt+drag a marker on the ruler (or drag the end of a ranged one), or set Duration in the marker editor. Shown as bands on the ruler and bars on clips; both ends snap.
- **Markers**: drag a marker's flag to move it, click to jump to it, hover for a tooltip, double-click a clip marker to edit it.
- **Export**: File > Export > Timeline as EDL (CMX3600 with dissolves and speed changes), Timeline Markers to EDL or CSV.
- **Undo history**: Edit > History > Open History Window; click a step to go back to it.
- **Edit Index**: right-click the header to choose columns; durations of ranged markers.

## Faster on big projects
Measured on a 1-hour project with 16 tracks and about 1500 clips:
- Undo uses about 5x less memory per step.
- Autosave no longer pauses the editor (25 ms -> 0.2 ms on the interface).
- Blade, ripple delete and undo respond about a third faster; the Edit Index updates about 4x faster.

## Notes
- Projects are saved in a new format version (ranged markers); projects from 0.3.x open unchanged, but older Kinoklip versions cannot open projects saved by this one.

## Known limitations
- EDL export writes one video track (the format allows only one); AAF / FCPXML are not available yet.
- Marker durations cannot be typed in the Edit Index table yet.
- 4K HEVC may still drop a frame or two when you press Space immediately after importing.
- Colour grading and compositing pages are planned for v4.
