Kinoklip 0.1.0-alpha.2 - second alpha. Built from the feedback on alpha.1: Kinoklip now aims to be [DaVinci Resolve](https://www.blackmagicdesign.com/products/davinciresolve)'s Edit page built in [Qt](https://www.qt.io), with the [KDE Breeze](https://invent.kde.org/plasma/breeze) look. Still an alpha: expect bugs, keep backups.

## Download and run (Linux x86_64)
1. Download `Kinoklip-x86_64.run`.
2. Make it executable: right-click > Properties > "Is executable", or `chmod +x Kinoklip-x86_64.run`.
3. Double-click it (or run `./Kinoklip-x86_64.run`). The first start unpacks into `~/.cache/kinoklip` (a few seconds); later starts are fast. Kinoklip now adds itself to the application menu automatically (opt out with `--uninstall-desktop-entry`).

Needs: x86_64 Linux, OpenGL 3.3, `zstd` + `tar` (or `bsdtar`). Runs natively on Wayland and on X11. `kinoklip-x86_64.tar.zst` is the same app as a portable folder; `SHA256SUMS.txt` has checksums.

## What's new since alpha.1
**Fixes**
- Switching Settings > Color Theme no longer crashes, and the whole window (menu bar, toolbars, panels, icons) switches consistently, including "Default (System)" on Plasma.
- The bundle now includes the Qt Wayland platform plugin (alpha.1 silently fell back to X11).
- The desktop portal now recognises the app (no more "App info not found" message).
- Visual fixes: menu arrows no longer overlap text, viewer zoom/quality boxes have proper spacing, Deliver presets no longer clip their names, Preferences layout cleaned up; one spacing scale throughout.

**Editing like Resolve**
- Ripple delete and ripple cut (Ctrl+Shift+X) on clips, gaps and in/out ranges; lift (Backspace) and extract (Delete) on marked ranges; linked clips follow, locked tracks never change, one undo step each.
- Windows Resolve default keyboard layout (152 commands, e.g. Ctrl+\ to split, Shift+2..8 for pages) and keyboard profiles: duplicate, rename, import, export and switch in Keyboard Customization.
- Mouse wheel like Resolve: wheel scrolls tracks, Ctrl+wheel scrolls time, Alt+wheel zooms around the playhead, Shift+wheel changes track height. "Classic" mapping and "zoom around mouse" available in Preferences > Editing.
- New: auto track selectors, edit-point selection and trimming keys, three-point editing, replace (F11), fit to fill, append, ripple overwrite, swap / shuffle edits, match frame (F), dynamic trim (W), paste attributes, clip markers, marker editor, clip duration (Ctrl+D) and speed (R) dialogs, transition alignment and edge dragging.
- 185 Edit-page behaviours checked against a written spec (`docs/behavior-spec.md`).

**Keyframes**
- Keyframe editor on the timeline: open it with the buttons in a clip's corner; rows per section and parameter; select, drag, copy, paste, delete keys.
- Curve editor with bezier handles: Linear, Smooth, Ease In, Ease Out, Ease In-Out, Static, Flatten.
- Section keyframe diamonds in the inspector (key a whole section at once).

**Layout and settings like Resolve**
- Page bar Media / Cut / Edit / Compositing / Color / Audio / Deliver (pages not built yet are visible but disabled), Resolve-style viewer headers and timeline toolbar with zoom slider, effects library with categories.
- Deliver: full Render Settings (resolution incl. Match Timeline, quality or bitrate limit, encoder choice incl. NVENC / VAAPI / QSV, key frame interval, audio format, file naming).
- Project Settings and Preferences (System / User) organised like Resolve's.

**Safety**
- Crash recovery: after a crash Kinoklip offers to restore the autosave.
- File > Open Recent; relink offline media; damaged project files and broken media no longer crash the app.

## Known limitations
- Colour grading, compositing and audio pages are not built yet.
- 25 shortcuts are marked "unsure" in `docs/keymap-resolve-windows.md`; please report any that differ from Resolve.
- No audio while shuttling or playing in reverse; no viewer edit overlay or two-up trim view yet.
- Options the engine can't do yet are shown disabled with a tooltip (e.g. export frame rate different from the timeline, colour tags, image scaling modes).
- Intel VAAPI decode/encode and the desktop-portal registration have not yet been verified on real Iris Xe / Plasma hardware.
