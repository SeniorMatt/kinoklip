Kinoklip 0.3.1-alpha.1 - v3 polish rounds 2 and 3: on-screen transform and crop handles in the viewer, the Edit Index, multi-clip Inspector edits, faster and in-sync first play, offline media handling, and many smaller Edit page details. Still an alpha: expect bugs, keep backups.

## Download and run (Linux x86_64)
1. Download `Kinoklip-x86_64.run`.
2. Make it executable: right-click > Properties > "Is executable", or `chmod +x Kinoklip-x86_64.run`.
3. Double-click it (or run `./Kinoklip-x86_64.run`). The first start unpacks into `~/.cache/kinoklip`; later starts are fast.

Needs: x86_64 Linux, OpenGL 3.3, `zstd` + `tar` (or `bsdtar`). Wayland and X11. `kinoklip-x86_64.tar.zst` is the same app as a portable folder; `SHA256SUMS.txt` has checksums.

## Viewer
- **On-screen Transform controls** (viewer mode menu, or the viewer's right-click menu): drag the picture to move it, corner and edge handles to scale (around the anchor point), the knob above the top edge to rotate, the centre cross to move the anchor point. Shift toggles the aspect lock, snaps rotation to 15 degrees and keeps moves on one axis. Every drag is one undo step and keys the parameter when it is animated.
- **Crop** mode with edge and corner crop handles.
- Titles can be positioned by dragging them in the viewer.
- Right-click menu on the viewers; "Media Offline" notice for missing files.

## Edit Index
- The Edit Index panel lists every edit (name, track, source and record in / out, duration) or every marker (colour, name, timecode, notes). Click a row to go there; search and filter by marker colour; edit marker names and notes in place; Delete removes the selected marker.

## Timeline
- Track header menu: track height presets (small / medium / large), Move Track Up / Down, Enable / Mute / Solo.
- Timeline View Options: thumbnails as filmstrip, head and tail, or name only; waveforms on / off; show source timecode on clips; height of all tracks.
- Missing media shows as red "Media Offline" clips; Relink searches subfolders; Relink Selected Clips.
- Clip > Increase / Decrease Clip Speed by 10%.
- Ruler menu: Modify Marker. Ctrl+wheel scrolls a tenth of the view per notch.
- Undo / redo name every step (Edit > Undo "Move Clip", ...).

## Inspector
- With several clips of the same kind selected, a change applies to all of them in one undo step; differing values show "Mixed".

## Playback
- First play right after import: picture and sound now start together (sound used to run ahead), with fewer dropped frames; the hardware decoder is warmed up at start-up.
- Cleaner shuttle sound at 4x - 8x.

## Other
- The Cut page viewer accepts drops for its six smart edits.
- Audio page: track names are readable in the headers; Space and the other shortcuts work in the floating viewer and the EQ / Dynamics windows.
- Deliver page: a "Render complete" notice when the queue finishes.
- Preferences > Editing: optional trim view with effects and transforms (slower; off by default).

## Known limitations
- Normalize Audio Levels, ranged markers, an Edit Index export (EDL) and an undo history list are not implemented yet.
- 4K HEVC may still drop a frame or two when you press Space immediately after importing.
- Colour grading and compositing pages are planned for v4.
