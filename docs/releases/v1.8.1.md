## [Download Kinoklip 1.8.1 for Linux (AppImage)](https://github.com/SeniorMatt/kinoklip/releases/download/v1.8.1/Kinoklip-x86_64.AppImage)

Open it with [Gear Lever](https://flathub.org/apps/it.mijorus.gearlever) (or update it there), or make it executable (right-click > Properties > "Is executable") and double-click it. If double-clicking shows nothing, install `fuse3` or run it with `--appimage-extract-and-run`.

**New to Kinoklip? Read the [guide](https://github.com/SeniorMatt/kinoklip/blob/main/docs/guide/readme.md).** Questions and ideas: join us on [Discord](https://discord.gg/pCeHnvDn3x). Website: [seniormatt.github.io/kinoklip](https://seniormatt.github.io/kinoklip/).

### Fixed
- Memory no longer grows until the system runs out while playing slow-motion clips, and fullscreen plays again after that ([#8](https://github.com/SeniorMatt/kinoklip/issues/8))
- The mouse wheel scrolls the Media Pool thumbnails one row per notch (it was a third of a row) and follows the system's wheel setting
- Ripple trims keep sync-locked tracks in sync from every path, including Change Clip Duration and transitions that need frames
- Ripple Start to Playhead puts the playhead on the new cut instead of a clip on another track
- Add Effect menu: no empty row below the folders, and search lists name matches first (Enter adds the top one)
- A memory leak at exit in the compositor

### New
- Compositing page sound, like Resolve's Fusion page: an Audio on/off button next to the transport controls, and in the MediaIn Inspector: Audio (Timeline or Solo this clip) and Sound Offset ([#7](https://github.com/SeniorMatt/kinoklip/issues/7))
- Preferences: explanations show when you hover a setting instead of as text under it, and one message after Save tells you when a change needs a restart
- Playback statistics and the log file show output frames held, decoders open and render memory
- Ctrl+Tab and Ctrl+Shift+Tab switch between timeline tabs
- Preferences > Editing: "Sync Lock on new tracks" (on by default, as in Resolve)
- Hold Shift while dragging on the timeline to flip snapping for that drag
- Effects and transitions from the Inspector, the Effects library and drag and drop go to every selected clip
