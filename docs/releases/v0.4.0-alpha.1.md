Kinoklip 0.4.0-alpha.1 - Project Manager, single-file projects, viewer guides and 54 new effects. Still an alpha: expect bugs, keep backups.

## Download and run (Linux x86_64)
1. Download `Kinoklip-x86_64.run`.
2. Make it executable: right-click > Properties > "Is executable", or `chmod +x Kinoklip-x86_64.run`.
3. Double-click it (or run `./Kinoklip-x86_64.run`). The first start unpacks into `~/.cache/kinoklip`; later starts are fast.

Needs: x86_64 Linux, OpenGL 3.3, `zstd` + `tar` (or `bsdtar`). Wayland and X11. `kinoklip-x86_64.tar.zst` is the same app as a portable folder; `SHA256SUMS.txt` has checksums.

## New

### Project Manager
- Shown when Kinoklip starts (Preferences can reopen the last project instead), and from File > Project Manager (Shift+1).
- Your projects live in a project library (`~/Videos/Kinoklip Projects`, changeable in Preferences): cards with a poster frame, name, date, duration, resolution and frame rate, or a list with sortable columns; search, sort, card size, Recent Projects.
- Folders (drag projects into them), New, Open, Rename (F2), Duplicate, Delete (to the trash), Show in File Manager, Import, Export. The open project is protected; a broken project file shows an error card.

### Single-file projects
- New Project asks for the kind: **Single file** (default) or **Linked** (media stays where it is, as before).
- A single-file project is one `.kinoklip` file holding the timelines and every video, image and sound you import: imports copy the media in (with progress and Cancel), so you can delete or move the originals and move the project anywhere. Media plays straight from inside the file.
- File > Pack Project (linked to single file), Unpack Project, Compact Project (removes unused media and old data, shows the sizes first), Verify Project File (with Repair). Save As converts between the two kinds.
- The Media Pool marks each clip as stored in the project or linked (badge, Location column).
- The file is a standard ZIP: any unzip tool can get your media back out. It stores no folder paths or user names. Saving never rewrites the media, and a crash during a save keeps the previous save.

### Viewer guides
- View > Show Rulers, then drag guides out of the rulers (or View > Guides > Add Horizontal / Vertical Guide). Drag to move, drag back onto a ruler to remove, double-click for an exact position.
- Lock, Snap to Guides (on-screen transform, crop and anchor drags snap), Clear, Guide Color, guide presets (Centre Cross, Rule of Thirds, your own).
- View > Safe Area (action safe, title safe, centre mark, aspect markers 2.39:1 to 9:16) and View > Show Grid (thirds, 4 x 4, custom).
- Guides are saved with each timeline and never appear in renders or exports.

### Effects (62 video effects, in folders: Blur, Color, Distort, Key, Light, Stylize, Time, Transform)
- **Green screen**: Chroma Key with an eyedropper on the viewer (click or drag over the background), tolerance, softness, edge shrink / grow, edge blur, spill removal and a matte view; masks work as garbage mattes. Also Luma Key and HSL Key.
- Color: Exposure, Temperature / Tint, Levels, Invert, Black and White, Posterize, Color Balance.
- Blur and light: Box, Directional, Radial and Zoom Blur, Glow.
- More colour: Curves (master and R / G / B, edited on a curve graph), HSL Adjust, Apply LUT (.cube files), Vibrance, Channel Mixer, Duotone.
- More blur and light: Unsharp Mask, Tilt-Shift, Lens Blur, Noise Reduction, Light Rays, Bloom, Halation, Lens Flare.
- Stylize: Film Grain, Chromatic Aberration, Edge Detect, Emboss, Stroke, Pixelate (hexagons, dots, diamonds), Halftone, Scanlines, Pencil Sketch, Abstraction, Prism.
- Distort and transform: Lens Distortion, Ripple, Wave, Twirl, Bulge / Pinch, Kaleidoscope, Mirror Split, Corner Pin, Camera Shake, Feathered Crop, Tile.
- Time (new folder): Echo, Strobe, Flicker.
- The HSL Key's hue has an eyedropper too; Directional, Radial and Zoom Blur can spread past the clip's edge.
