## [Download Kinoklip 1.4 for Linux (AppImage)](https://github.com/SeniorMatt/kinoklip/releases/download/v1.4.0/Kinoklip-x86_64.AppImage)

Open it with [Gear Lever](https://flathub.org/apps/it.mijorus.gearlever) (or update it there), or make it executable (right-click > Properties > "Is executable") and double-click it. If double-clicking shows nothing, install `fuse3` or run it with `--appimage-extract-and-run`.

**New to Kinoklip? Read the [guide](https://github.com/SeniorMatt/kinoklip/blob/main/docs/guide/readme.md).** Questions and ideas: join us on [Discord](https://discord.gg/pCeHnvDn3x).

### New
- Background Removal (AI, optional): cuts a person out of a clip with a model that runs on your computer. Effects library > Key; the model (14 MB) is downloaded only when you ask ([how to use it](https://github.com/SeniorMatt/kinoklip/blob/main/docs/guide/remove-a-background.md))
- Ctrl+V in the Media Pool imports copied files or a copied picture
- Menu layout: choose Streamlined in Preferences > UI Settings for shorter menus grouped by task, with a menu for the page you are on; Resolve (the default) keeps the menus as in DaVinci Resolve ([details](https://github.com/SeniorMatt/kinoklip/blob/main/docs/guide/getting-started.md#choose-a-menu-layout))

### Fixed
- Short stall right after a cut, which could hide the first frames of an animation
