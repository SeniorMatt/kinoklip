Kinoklip 0.3.5-alpha.1 - the real Kinoklip icon, and smoother window resizing on Wayland. Still an alpha: expect bugs, keep backups.

## Download and run (Linux x86_64)
1. Download `Kinoklip-x86_64.run`.
2. Make it executable: right-click > Properties > "Is executable", or `chmod +x Kinoklip-x86_64.run`.
3. Double-click it (or run `./Kinoklip-x86_64.run`). The first start unpacks into `~/.cache/kinoklip`; later starts are fast.

Needs: x86_64 Linux, OpenGL 3.3, `zstd` + `tar` (or `bsdtar`). Wayland and X11. `kinoklip-x86_64.tar.zst` is the same app as a portable folder; `SHA256SUMS.txt` has checksums.

## Changed
- **New icon**: the hand-drawn pixel-art Kinoklip icon, for the window, the task manager, the application menu and the bundle. The menu / task-manager icon installed by older versions is replaced on the first start (until now a new icon never replaced the installed one).
- **Window resizing on Wayland**: the window content follows the window edges more closely while you drag them. Buffer swaps no longer wait for the compositor, so a frame drawn at the previous size is replaced sooner, and the Edit page lays its panels out once per step instead of twice. Please tell us how it feels on your desktop.
  - To measure it: start with `QT_LOGGING_RULES=kk.ui.resize.debug=true` and drag a window corner; each resize step and a summary per drag are logged.
  - `KK_SWAP_INTERVAL=1` restores the previous behaviour for comparison.
