Kinoklip 0.3.3-alpha.1 - wider default side panels on the Edit page. Still an alpha: expect bugs, keep backups.

## Download and run (Linux x86_64)
1. Download `Kinoklip-x86_64.run`.
2. Make it executable: right-click > Properties > "Is executable", or `chmod +x Kinoklip-x86_64.run`.
3. Double-click it (or run `./Kinoklip-x86_64.run`). The first start unpacks into `~/.cache/kinoklip`; later starts are fast.

Needs: x86_64 Linux, OpenGL 3.3, `zstd` + `tar` (or `bsdtar`). Wayland and X11. `kinoklip-x86_64.tar.zst` is the same app as a portable folder; `SHA256SUMS.txt` has checksums.

## Changed
- The Media Pool / Effects column and the Inspector are wider by default (about a quarter of the window each; the viewers share the rest).
- They keep that share when the window starts small and is then maximised (before, only the viewers grew and the side panels stayed narrow).
- Your saved Edit page layout from older versions is reset to the new widths once; after you drag a column divider, your own widths are kept as before.

Nothing else changed since 0.3.2-alpha.1.
