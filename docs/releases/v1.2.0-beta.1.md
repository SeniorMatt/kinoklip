## [Download Kinoklip 1.2 Beta for Linux (AppImage)](https://github.com/SeniorMatt/kinoklip/releases/download/v1.2.0-beta.1/Kinoklip-x86_64.AppImage)

Open it with [Gear Lever](https://flathub.org/apps/it.mijorus.gearlever) (or update it there), or make it executable (right-click > Properties > "Is executable") and double-click it. If double-clicking shows nothing, install `fuse3` or run it with `--appimage-extract-and-run`. Beta: keep backups.

**New to Kinoklip? Read the [guide](https://github.com/SeniorMatt/kinoklip/blob/main/docs/guide/readme.md).** Questions and ideas: join us on [Discord](https://discord.gg/pCeHnvDn3x).

### New
- [OpenTimelineIO](https://opentimeline.io) import and export (issue #5)
- Command-line interface (`kinoklip clip list`, `kinoklip clip add` and more)
- Model Context Protocol server, with live control of the open window
- Planar tracker node and Follow Track
- Match Move, Surface Tracker and Warper
- Clip stabilization in the Inspector
- Smooth Cut and the rest of the video transitions
- Missing generators, templates and effects
- Multi-frame effects: Motion Trails, Smear, Motion Blur, Frame Replacer, Deflicker and more
- Template looks: CCTV, Digital Glitch, Drone Overlay, DSLR, DVE, Video Call, Video Camera
- Fade curves shaped with the mouse on the clip
- Audio effects on audio clips
- Inspector > Audio: Pitch and a four-band clip Equalizer
- Title layers: several text and shape layers in one title
- Colour emoji in titles and subtitles, in the viewer and in exports
- Media Pool Live Media Preview
- Dragging over a page button opens that page
- Settings import and export
- Vim keyboard preset
- Help > Export Log File
- Menu and panel reference in the guide

### Fixed
- Fades no longer slide outside the clip after a cut, trim or reload
