## [Download Kinoklip 1.3 Beta for Linux (AppImage)](https://github.com/SeniorMatt/kinoklip/releases/download/v1.3.0-beta.1/Kinoklip-x86_64.AppImage)

Open it with [Gear Lever](https://flathub.org/apps/it.mijorus.gearlever) (or update it there), or make it executable (right-click > Properties > "Is executable") and double-click it. If double-clicking shows nothing, install `fuse3` or run it with `--appimage-extract-and-run`. Beta: keep backups.

**New to Kinoklip? Read the [guide](https://github.com/SeniorMatt/kinoklip/blob/main/docs/guide/readme.md).** Questions and ideas: join us on [Discord](https://discord.gg/pCeHnvDn3x).

### New
- Voice-over recording onto an armed audio track (Playback > Record Voice-Over, Ctrl+Alt+R)
- Dragging files over a closed panel's button opens that panel
- Windows and dialogs open big enough for their content

### Fixed
- Playback drops when the timeline scrolls during playback (issue #2)
- Lag when playback crosses into a clip with keyframes
