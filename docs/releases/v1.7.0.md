## [Download Kinoklip 1.7 for Linux (AppImage)](https://github.com/SeniorMatt/kinoklip/releases/download/v1.7.0/Kinoklip-x86_64.AppImage)

Open it with [Gear Lever](https://flathub.org/apps/it.mijorus.gearlever) (or update it there), or make it executable (right-click > Properties > "Is executable") and double-click it. If double-clicking shows nothing, install `fuse3` or run it with `--appimage-extract-and-run`.

**New to Kinoklip? Read the [guide](https://github.com/SeniorMatt/kinoklip/blob/main/docs/guide/readme.md).** Questions and ideas: join us on [Discord](https://discord.gg/pCeHnvDn3x).

### New: the Compositing page
Read [the Compositing page](https://github.com/SeniorMatt/kinoklip/blob/main/docs/guide/compositing-page.md).
- Merge and Transform in full: Edges, Pivot, Invert Transform, Alpha Gain, Burn In, Filter Method, Reference Size, 33 apply modes and the Over / In / Held Out / Atop / XOr operators
- Settings on every node: Blend, process R / G / B / A, mask options
- Motion Blur on Merge and Transform
- New tools: Luma Keyer, Delta Keyer, Corner Positioner, B-Spline mask; rounded Rectangle mask and mask paint modes
- Viewer tools: A/B buffers with a split wipe, channel views, checker background, show/hide controls, lock, 100% zoom, loop modes
- Node editor: drop a node on a link to insert it, tile pictures, hover tips, Replace With, Find (Ctrl+F), tile colours, Paste Settings, Shift-drag to remove a link. Fit Nodes to View is now Shift+F

### New
- Deliver: Individual clips renders each clip to its own file, with handles and naming options
- Clip Attributes: video frame rate override and alpha mode
- Create New Timeline: Empty Timeline, Use Project Settings and the audio track type
- Search in the transition type list and in the LUT browser
- Mouse back and forward buttons work on every page, in the Project Manager and in Media Storage
- Render Queue: double-click a job to edit it, and a right-click menu
- Effects library: right-click to add an effect to selected clips, the selected edit point or the playhead
- Mixer: double-click a track name to rename it

### Fixed
- The viewer follows the timeline when you click the Edit Index or the Keyframes panel
- Keyframe panel keys no longer take over Mark In, Mark Out and play on the Edit page
- Small screens: the Effects list, the Cut toolbar, the LUT browser and the viewer's marks text fit
- Shift+Delete and Ctrl+Backspace work while a mask or keyframe is selected
