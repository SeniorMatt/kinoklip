## [Download Kinoklip 1.1.5 Beta for Linux (AppImage)](https://github.com/SeniorMatt/kinoklip/releases/download/v1.1.5-beta.1/Kinoklip-x86_64.AppImage)

Open it with [Gear Lever](https://flathub.org/apps/it.mijorus.gearlever) (or update it there), or make it executable (right-click > Properties > "Is executable") and double-click it. Beta: keep backups.

**New to Kinoklip? Read the [guide](https://github.com/SeniorMatt/kinoklip/blob/main/docs/guide/readme.md).**

Your saved panel column widths are reset once by this update.

### Bog fixes
- Option: stop playback when the playhead is moved
- Option: pressing the ruler moves the playhead at once
- Option: focus the search field when a panel is opened from the keyboard
- Option: ripple delete acts on the clips under the playhead when nothing is selected
- Pressing the playhead head no longer steps it back a frame
- Timeline no longer scrolls when a track above the view changes
- Tiny transitions are easier to select
- Open in Timeline opens a compound clip at the matching frame
- Proportional link no longer changes by itself
- Deleting several keyframes keeps the value at the playhead
- Clip keyframe marks include masks and grades
- Keyframe easing commands
- Effects > Region Blur
- Colour error and wasted work when scaling some frame sizes

### New
- Edit everything during playback
- Option: keep playing or stop after an edit during playback
- Keyframes panel switches between Keyframes and Curves
- Playhead snaps to keyframes
- Keyframes snap to keyframes, markers and marks
- Middle drag pans the Keyframes view
- Middle click adds two crossing guides
- Guides can be taken from up to 12 px away
- Selection box starts above and below the tracks
- Every panel size is remembered
- Workspace > Reset UI Layout

### Fixed
- Stutter at cuts during playback
- Audio waveforms follow clip volume and show loudness
- Single viewer mode squeezing the side columns
- Report a Bug and Guide buttons not opening the browser on Wayland
- Copy Link message when no browser opens
- Text cut off in Project Settings, Preferences, the mixer, the Color page and Deliver
