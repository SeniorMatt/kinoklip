## [Download Kinoklip 1.5 for Linux (AppImage)](https://github.com/SeniorMatt/kinoklip/releases/download/v1.5.0/Kinoklip-x86_64.AppImage)

Open it with [Gear Lever](https://flathub.org/apps/it.mijorus.gearlever) (or update it there), or make it executable (right-click > Properties > "Is executable") and double-click it. If double-clicking shows nothing, install `fuse3` or run it with `--appimage-extract-and-run`.

**New to Kinoklip? Read the [guide](https://github.com/SeniorMatt/kinoklip/blob/main/docs/guide/readme.md).** Questions and ideas: join us on [Discord](https://discord.gg/pCeHnvDn3x).

### New: Vim mode
Edit the whole project from the keyboard, the Vim way. Turn it on in Preferences > Keyboard or Kinoklip > Vim Mode. Read [Vim for Kinoklip](https://github.com/SeniorMatt/kinoklip/blob/main/docs/guide/edit-with-vim-keys.md) and keep the [cheat sheet](https://github.com/SeniorMatt/kinoklip/blob/main/docs/guide/vim-cheat-sheet.md) at hand.
- Normal, Insert and Visual modes with a mode line; Space is the leader, with a pop-up list of what comes next
- Timeline grammar: clips are words (`w b e`), tracks are lines (`j k gg G`), operators with counts, motions and text objects (`d3w`, `dd`, `yy`, `cw`, `dip`), registers, macros (`q`, `@`), marks, `.` repeat, `/` and `?` search, `f t` to find a clip by name
- Command line `:` with completion and history: `:w`, `:q`, `:e`, `:bn`, jump to a frame or timecode, `:set`, `:nmap`, any command with `:action`
- Pickers on the leader: media, commands, effects and transitions, timelines, markers, bins, help, keys
- Every panel: move between panels with Ctrl+H/J/K/L and Ctrl+W, pages with `gt gT`; lists and bins (Media Pool, Effects, render queue); the Inspector (step values with Ctrl+A/Ctrl+X, type values and title text, reset, set keyframes); the keyframe and curve editor; node graphs; the audio mixer; transitions on cuts
- Change any key in Keyboard Customization > Vim keys or in a vimrc file; keys follow their position, so other keyboard layouts work
- The old Vim keyboard preset is replaced by this mode and your choice carries over
