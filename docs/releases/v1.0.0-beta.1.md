## [Download Kinoklip 1.0.0 Beta for Linux (AppImage)](https://github.com/SeniorMatt/kinoklip/releases/download/v1.0.0-beta.1/Kinoklip-x86_64.AppImage)

Open it with Gear Lever, or make it executable (right-click > Properties > "Is executable") and double-click it. This is the first beta: most things work, but keep backups.

**New to Kinoklip? Read the [guide](https://github.com/SeniorMatt/kinoklip/blob/main/docs/guide/readme.md).**

### New: the Compositing page
- Give any clip a **node graph**: select it and press **Shift+5** (or right-click it > **Open in Compositing Page**). It starts as MediaIn > MediaOut, so nothing changes until you add nodes.
- **Nodes**: Merge (with blend modes), Dissolve, Transform, Crop, Resize, Letterbox, Background, Text, Fast Noise, Rectangle / Ellipse / Polygon masks, Color Corrector, Channel Booleans, and every Edit page effect (green screen keys included).
- **Two viewers**: press **1** or **2** to show the selected node on the left or right; on-screen handles for Transform and the masks.
- **Node editor**: drag from a port to connect, drop a node onto a link to insert it, **Shift+Space** to find any node, copy / paste, every change can be undone.
- The result plays on the Edit page and renders exactly the same; clips with a composition show a small badge on the timeline.

Projects saved by this version (format 15) cannot be opened by older versions.
