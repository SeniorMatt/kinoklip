Kinoklip 0.2.0-alpha.1 - first alpha of v2 ("deeper editing"): masks, retiming, proxies, multicam, bins, audio level lines and more, plus the new Kinoklip colour scheme as the default. Still an alpha: expect bugs, keep backups.

## Download and run (Linux x86_64)
1. Download `Kinoklip-x86_64.run`.
2. Make it executable: right-click > Properties > "Is executable", or `chmod +x Kinoklip-x86_64.run`.
3. Double-click it (or run `./Kinoklip-x86_64.run`). The first start unpacks into `~/.cache/kinoklip`; later starts are fast.

Needs: x86_64 Linux, OpenGL 3.3, `zstd` + `tar` (or `bsdtar`). Wayland and X11. `kinoklip-x86_64.tar.zst` is the same app as a portable folder; `SHA256SUMS.txt` has checksums.

## Look
- **Kinoklip colour scheme** (new default): neutral charcoal with a warm accent. Breeze Dark, Breeze Light and the other KDE schemes stay available under Settings; a scheme you chose before is kept.
- Everything Kinoklip draws itself (timeline clips, waveforms, track badges, playhead, rulers, keyframe and curve editors, media pool tiles, viewer overlays) now follows the active colour scheme. Clip colour labels and flags keep their own colours.

## Editing (v2)
- **Masks**: rectangle, ellipse, polygon and Bezier masks on clips with feather, expand, invert, opacity and add / subtract / intersect, all keyframable, edited on the viewer.
- **Speed changes and retiming**: change clip speed, speed points and ramps, reverse, freeze frame; nearest frame, frame blend or optical flow; pitch-corrected audio.
- **Linked clips move together across tracks**: dragging a video clip from V1 to V2 takes its audio from A1 to A2.
- **Audio level lines and fades**: drag the volume line on audio clips, Alt+click adds a keyframe; fade handles at the top corners of video and audio clips.
- **Clip Attributes** (Clip menu or right-click): pixel aspect, data levels, deinterlacing, rotation, audio channel mapping, start timecode.
- **Adjustment clips, generators** (solid colour, gradients, test patterns) and a **subtitle track** with SRT import / export.
- **Multicam**: build a multicam clip from several angles synced by audio waveform, timecode or in points; switch and cut angles from the multicam viewer.
- **Stacked timelines** (View menu): a second timeline above the editor, drag clips between them.
- Timeline tabs, compound clips and nested timelines from alpha.4.

## Media pool (v2)
- Bins inside bins, **smart bins** that fill themselves from rules, **power bins** shared by all projects.
- 16 clip colours and 16 flags on media and timeline clips, with a colour filter.
- Metadata panel with editing of several clips at once.
- Usage indicator, Select Clips in Timeline, Remove Unused Clips, Find in Media Pool (Alt+F).

## Performance
- **Proxy and optimized media** (H.264 fast-decode) with Playback > Proxy Handling.
- **Render cache** for heavy sections (effects, masks, retimes, nested timelines).

## Notes
- Projects are saved in a new format version; projects from 0.1.x open unchanged, but older Kinoklip versions cannot open projects saved by this one.
- New shortcuts: New Bin (Ctrl+Shift+N), Find in Media Pool (Alt+F). The full list is in `docs/keymap-resolve-windows.md`.

## Known limitations
- Colour grading, compositing and audio pages are not built yet (roadmap v2.5).
- Mask tracking is not implemented yet.
- The multicam viewer is slow on software OpenGL.
- Deinterlacing and data levels only work with GPU rendering; Clip Attributes apply per media item, not per clip.
- Intel VAAPI paths are still unverified on real Iris Xe hardware.
