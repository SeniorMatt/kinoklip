## [Download Kinoklip 1.8 for Linux (AppImage)](https://github.com/SeniorMatt/kinoklip/releases/download/v1.8.0/Kinoklip-x86_64.AppImage)

Open it with [Gear Lever](https://flathub.org/apps/it.mijorus.gearlever) (or update it there), or make it executable (right-click > Properties > "Is executable") and double-click it. If double-clicking shows nothing, install `fuse3` or run it with `--appimage-extract-and-run`.

**New to Kinoklip? Read the [guide](https://github.com/SeniorMatt/kinoklip/blob/main/docs/guide/readme.md).** Questions and ideas: join us on [Discord](https://discord.gg/pCeHnvDn3x). Website: [seniormatt.github.io/kinoklip](https://seniormatt.github.io/kinoklip/).

### New: Kinoklip in your language
- Russian, German, Ukrainian and Spanish
- Preferences > User > Language (takes effect after a restart)

### New: Sync Lock
- Every track has a Sync Lock button next to the track lock, on by default
- Ripple trims, ripple delete, insert and close gap keep all sync-locked tracks in sync: clips on other tracks are cut and moved so nothing slips
- Turn Sync Lock off on a track to ripple without it
- Auto Select now only picks the tracks that cuts and edits at the playhead apply to
