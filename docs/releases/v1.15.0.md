### Fixed
- No more start-up crash on some AMD cards (RX 7900 XTX): hardware encoders are tested only when needed, in a separate process, so a driver crash can't take Kinoklip down; a failed hardware render is done again in software (issue #18)
- Deliver page: a Test Hardware Encoders button, and `KINOKLIP_HWACCEL=off` also turns off hardware encoding

### New: plugins
- Kinoklip's own plugins: shader effects, transitions, preset packs and Python scripts, with Preferences > Plugins to install, turn on and off, and reload them
- Writing and copying plugins is easy for people and for AI assistants: a writing-plugins guide, `kinoklip plugin create` / `copy_builtin` / `validate` / `pack`, and the same tools in the MCP server
- OpenFX video plugins (the standard used by Natron and Resolve): the free openfx-misc pack works (over 100 effects); G'MIC works when installed
- LV2 and CLAP audio plugins on the Audio page and as clip audio effects, with automation and latency compensation: LSP, ZAM and x42 work
- Plugins are checked in a separate process the first time, so a crashing plugin goes on a bad-plugin list instead of crashing Kinoklip; scanning runs in the background
- 394 bundled GL Transitions, transition presets at an edit point, and a Plugins folder in the Compositing node list

### New
- Color Space Transform, ACES Transform, Gamut Mapping, Chromatic Adaptation and Color Compressor effects
- DCTL and DCTL Transition: load DaVinci CTL (.dctl) files as effects and transitions
- Follow Subject > Track: a mask on the Edit page follows what is under it by itself
- Object Removal (Effects > Revival): hides people or objects that pass through a steady shot, no AI needed
- HDR export: ProRes with PQ / HLG, and a Mastering display setting for H.265, AV1 and ProRes
- Export Project Archive / Restore Project Archive (File > Project Tools)
- Bounce Mix to Track and Bounce Selected Tracks (Timeline menu)
- Trim Editor window (Trim menu)
- Clone Tool on the Media page: copy camera cards to several places with checksum verification
- More than one project library, and Open in New Window in the Project Manager
- Layout presets (Workspace > Layout Presets)
- Metadata import and export to CSV (File > Import / Export)
- FFV1 lossless export, and render presets for YouTube, Vimeo, X, TikTok, Instagram and Facebook
- EDL export with more than one video track
- Marker duration can be typed in the Edit Index
- LUTs are packed into single-file projects and found again after a project moves (relative paths)
- Color page thumbnails show the clip itself when a higher track covers it
- `kinoklip --graphics-check`: tests the graphics card and video decoding and says what works
- Faster timeline drawing with many clips
