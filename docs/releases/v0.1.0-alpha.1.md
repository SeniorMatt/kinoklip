Kinoklip 0.1.0-alpha.1 - first alpha. Expect bugs; do not use it for important work yet.

## Download and run (Linux x86_64)
1. Download `Kinoklip-x86_64.run`.
2. Make it executable: right-click > Properties > "Is executable", or `chmod +x Kinoklip-x86_64.run`.
3. Double-click it (or run `./Kinoklip-x86_64.run`). The first start unpacks into `~/.cache/kinoklip` (a few seconds); later starts are fast.
4. Optional: `./Kinoklip-x86_64.run --install-desktop-entry` adds Kinoklip to the application menu.

Needs: x86_64 Linux, OpenGL 3.3 (any Intel/AMD/NVIDIA GPU from the last ~10 years), `zstd` + `tar` (or `bsdtar`). Tested on Arch (build container) and Linux Mint 22; built for KDE Linux / Plasma 6 (Wayland and X11).

`kinoklip-x86_64.tar.zst` is the same app as a portable folder (run `kinoklip-x86_64/AppRun`). `SHA256SUMS.txt` has checksums.

## What works
- Media / Edit / Deliver pages with a Resolve-like layout, real KDE Breeze look (Settings > Color Theme / Style).
- Import of common video, audio and image formats (incl. HEIC/AVIF, JPEG XL, EXR, PSD, camera RAW, image sequences).
- Multi-track timeline: select / trim / blade tools, ripple, roll, slip, slide, snapping, linked selection, markers, in/out, drag and drop, thumbnails and waveforms.
- Source viewer with in/out marks; insert / overwrite / place on top (F9 / F10 / F12).
- Inspector with keyframes (transform, crop, opacity, audio, effects, titles, transitions).
- GPU rendering (OpenGL 3.3): blur, brightness/contrast, saturation, sharpen, mirror, vignette, mosaic, drop shadow; cross dissolve, dip to color, wipe, push; text titles; solid colour.
- Playback with J/K/L shuttle, audio-synced clock, automatic preview quality.
- Hardware video decoding (VAAPI, CUDA, Vulkan) with software fallback.
- Export via Deliver page / render queue: H.264, H.265, AV1, ProRes, DNxHR, VP9 WebM, MKV, audio-only, image sequences, GIF; hardware encoding (NVENC, VAAPI, QSV) with software fallback.

## Known limitations
- Colour grading, compositing and audio-mixing pages are not in this release (see the roadmap).
- No audio while shuttling or playing in reverse; no scrub audio.
- Intel VAAPI decode/encode was wired and unit-tested but not yet verified on Iris Xe hardware.
- First alpha: some Resolve-style behaviours are still being matched (a behaviour-parity pass is in progress).
