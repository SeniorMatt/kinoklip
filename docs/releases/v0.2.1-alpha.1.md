Kinoklip 0.2.1-alpha.1 - v2.1: two editing improvements from the 0.2.0-alpha.1 feedback. Still an alpha: expect bugs, keep backups.

## Download and run (Linux x86_64)
1. Download `Kinoklip-x86_64.run`.
2. Make it executable: right-click > Properties > "Is executable", or `chmod +x Kinoklip-x86_64.run`.
3. Double-click it (or run `./Kinoklip-x86_64.run`). The first start unpacks into `~/.cache/kinoklip`; later starts are fast.

Needs: x86_64 Linux, OpenGL 3.3, `zstd` + `tar` (or `bsdtar`). Wayland and X11. `kinoklip-x86_64.tar.zst` is the same app as a portable folder; `SHA256SUMS.txt` has checksums.

## New
- **Double-click a compound clip** (or a nested timeline) on the timeline to open it in its own tab, with the playhead at the moment you clicked on.
- **Drag clips past the outermost track to create a new one**, like Resolve: above the top video track, or below the bottom audio track. Linked clips get a matching track (a new V3 pairs with A3). Only one track is added however far you drag; moving back removes it, and one undo reverts the whole move.

Everything from 0.2.0-alpha.1 is included (masks, retiming, proxies, multicam, bins, audio level lines, Clip Attributes, stacked timelines, the Kinoklip colour scheme).

## Known limitations
- Colour grading, compositing and audio pages are not built yet; the Cut page is in progress (roadmap v2.5).
- Mask tracking is not implemented yet.
- Intel VAAPI paths are still unverified on real Iris Xe hardware.
