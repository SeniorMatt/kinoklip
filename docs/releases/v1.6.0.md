## [Download Kinoklip 1.6 for Linux (AppImage)](https://github.com/SeniorMatt/kinoklip/releases/download/v1.6.0/Kinoklip-x86_64.AppImage)

Open it with [Gear Lever](https://flathub.org/apps/it.mijorus.gearlever) (or update it there), or make it executable (right-click > Properties > "Is executable") and double-click it. If double-clicking shows nothing, install `fuse3` or run it with `--appimage-extract-and-run`.

**New to Kinoklip? Read the [guide](https://github.com/SeniorMatt/kinoklip/blob/main/docs/guide/readme.md).** Questions and ideas: join us on [Discord](https://discord.gg/pCeHnvDn3x).

### New: Spline and keyframe loops
- Spline and Keyframes panels on the Compositing page, next to the node editor
- Keyframe loops: Loop, Ping-Pong, Relative and Linear, before and after the keys
- Reverse, Time Stretch and Step In for keyframes, on the Edit page too
- Read [Keyframe animation](https://github.com/SeniorMatt/kinoklip/blob/main/docs/guide/keyframe-animation.md)

### New
- Edit several clips at once: Inspector changes and on-screen move, scale, rotate and crop reach every selected clip
- Copy and paste transitions with Ctrl+C / Ctrl+V; Alt-drag copies a transition
- Standard transition and its length are project settings; choose the default type for new keyframes
- Convert the frame rate of a timeline that already has clips
- Write On for titles and the Compositing Text node, and a Typewriter title preset
- Graphical equalizer in the Inspector
- Background Removal for any subject in still pictures
- Search in Add Effect
- Media Pool: Save a Copy to Computer
- Dropping a node output on another node's output adds a Merge
- The viewer switches to the timeline when you click it, and the mouse back and forward buttons step through timelines
- Breeze Dark is the default theme
- Deliver starts on Match Timeline resolution
- New Preferences page: Timeline and Media Pool
- New fonts are picked up by themselves
- Help > Save Log File has a Memory section

### Fixed
- Memory kept growing while editing and rendering: open video decoders are capped and everything is released after a render
- Timeline thumbnails at a new track height show at once
- Playback stopped when closing the full-screen viewer
- Small screens: the Keyframes panel and node tools fit
