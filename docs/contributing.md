# Contributing

1. Read [coding-style.md](coding-style.md) before writing code: naming, doc comments on every
   public class and function, file headers, and a `readme.md` with a **How to extend** section in
   every module directory.
2. Read [docs/archive/plan.md](archive/plan.md) (the original architecture plan) for the module contracts, and
   [behavior-spec.md](behavior-spec.md) for how each feature must behave.
3. Shortcuts are never hard-coded: they go through the `ActionRegistry` and the keymap profiles.
   The Resolve keymap is generated by `scripts/keymap-resolve-windows.py`; do not edit
   `resources/keymaps/resolve-windows.json` by hand.
4. Follow the [clean-room policy](clean-room.md): nothing from Resolve or other Blackmagic products
   (code, icons, images, presets, documentation text, screenshots) is used or copied, Resolve is
   never installed or inspected, and pages and features use our own names (generic words like Cut,
   Edit, Color, Deliver, Media are fine; "Fusion", "Fairlight" are not). Every new asset gets a row
   in [attribution.md](../attribution.md) with its author and licence.
5. Write tests for logic (`tests/<area>/test_*.cpp`) and run them before committing; see
   [building.md](building.md).
6. Format before committing: `scripts/format.sh` (clang-format, `--check` for CI).
7. **Privacy:** never add code that sends or collects user data without explicit, per-use consent.
   Kinoklip has no telemetry, analytics, automatic crash reports or update pings, and makes no
   network requests; see [privacy.md](privacy.md).

## Reporting bugs
The easiest way: in Kinoklip, **Help > Report a Bug or Inconsistency...**. Choose a bug, something
that works differently from [DaVinci Resolve](https://www.blackmagicdesign.com/products/davinciresolve), or an idea; the dialog shows exactly which version and
system info it would add, and opens GitHub's report form in your browser with or without it. You
then describe what you did, what happened and what you expected, and submit it there. Without the
app, use [New issue](https://github.com/SeniorMatt/kinoklip/issues/new/choose) on GitHub; the forms
live in `.github/ISSUE_TEMPLATE/` (`scripts/check_issue_forms.py` checks them).
