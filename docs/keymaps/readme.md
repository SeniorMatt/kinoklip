# Keyboard presets

Kinoklip's default keys follow DaVinci Resolve on Windows ([its table](../keymap-resolve-windows.md)).
These built-in presets follow other editors instead; each page lists every key with a
confidence and the gaps. They are generated by `scripts/keymap-presets.py`.

| Preset | Profile id | Mapped | of which unsure | Default key kept | Unbound |
|---|---|---|---|---|---|
| [Vegas Pro](vegas-pro.md) | `vegas-pro` | 39 | 2 | 143 | 7 |
| [Premiere Pro (Windows)](premiere-pro.md) | `premiere-pro` | 87 | 7 | 98 | 7 |
| [Final Cut Pro (Ctrl for Command)](final-cut-pro.md) | `final-cut-pro` | 88 | 1 | 98 | 9 |
| [Avid Media Composer](avid-media-composer.md) | `avid-media-composer` | 43 | 2 | 131 | 13 |
| [Kdenlive](kdenlive.md) | `kdenlive` | 41 | 1 | 143 | 5 |
| [Shotcut](shotcut.md) | `shotcut` | 32 | 0 | 148 | 8 |

Import of your own files (Keyboard Customization > Import...): Premiere Pro `.kys` and Final
Cut Pro `.commandset` (XML plist) files are read too. The commands Kinoklip recognises get
their keys on top of the matching preset; unknown entries are skipped and counted.
See `src/ui/common/ForeignKeymaps.cpp`.

Vim mode is not a preset: it is an option that works with any of these. Its keys are in [vim-keys.md](vim-keys.md); the guide is [Vim for Kinoklip](../guide/edit-with-vim-keys.md) and a one-page list is the [Vim cheat sheet](../guide/vim-cheat-sheet.md).
