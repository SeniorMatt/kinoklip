# excludelist.txt -- which shared libraries the Linux bundle must NOT carry.
#
# Read by scripts/package_linux.sh (dependency walker) and scripts/check_bundle.sh.
#
# Format: one entry per line, "<kind> <soname-glob>", '#' starts a comment.
#   host      never bundled; the library must come from the user's system. The walker
#             does not descend into it either, so its own dependencies are not bundled.
#   fallback  prefer the host copy, but ship one in usr/lib/fallback/. The launcher links
#             only the ones the host lacks into usr/lib/fallback-active/ (searched via
#             RUNPATH), so a system copy always wins when it exists.
#
# Rule of thumb: a library goes to "host" when (a) it talks to the kernel, the GPU driver,
# the display server or a system daemon and must match it, or (b) the host graphics/font
# stack (Mesa, LLVM, freetype, ...) links it too: a bundled older copy would be loaded first
# and shadow the newer one that host library was built against ("undefined symbol" crashes).
# Every entry in (b) is present on any Arch/KDE system because systemd, Mesa or Qt need it.
#
# Target: KDE Linux (Arch based, Wayland, newer glibc/GCC than the Ubuntu 24.04 build host).

# ---- C++/GCC runtime: the host (GCC 15 on Arch) is newer than our GCC 13 and is
# backwards compatible; bundling would break host libraries (Mesa/LLVM) that need newer
