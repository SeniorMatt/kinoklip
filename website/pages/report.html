Report a bug

Something broke? Tell us.

You do not need to be an expert. Say what you did and what went wrong, in your own words. Bugs are tracked on GitHub so they do not get lost in chat.

Before you write

Two things that help most

  1. Use the newest version

    The problem may already be fixed. Get it from the download page.

  2. Save a log file

    In Kinoklip choose Help > Export Log File..., read the text, and save it. It says which decoder Kinoklip used for each video, whether the graphics card was used, and every warning. Nothing is written to disk or sent anywhere until you save the file yourself. You can attach it on the next step. How to send a log file

Tip: Help > Report a Bug or Inconsistency... inside Kinoklip fills in the version and system info for you. You see the text before anything is shared.
