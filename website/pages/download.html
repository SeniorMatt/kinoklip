Run it

Three steps

  1. Download the file

    Get Kinoklip-x86_64.AppImage from the latest release.

  2. Make it runnable

    With Gear Lever (easiest): install Gear Lever from your software centre, then open the AppImage with it. Kinoklip appears in your application menu, and Gear Lever keeps it updated.

    By hand: right-click the file, choose Properties, open Permissions and tick “Is executable”, or run this in a terminal:

    chmod +x Kinoklip-x86_64.AppImage

  3. Start it

    Start Kinoklip from the application menu, or double-click the file. The first thing you see is the Project Manager, where you make your first project. The getting started guide takes it from there.

If double-clicking shows nothing, your system may be missing FUSE, a small helper for AppImages. Install fuse3, or run the file with --appimage-extract-and-run:

./Kinoklip-x86_64.AppImage --appimage-extract-and-run

Requirements

What your computer needs

System
Linux on x86_64X11 or Wayland.
Graphics
OpenGL 3.3AMD, Intel or NVIDIA, integrated graphics included. Almost every computer from the last ten years has it.
Helper
FUSE (fuse3)Only if the AppImage does not start; see above for the workaround.
Optional
VA-API and a microphoneVA-API on Intel and AMD gives GPU decoding. PipeWire or PulseAudio microphones work for voice-over.

Updates and checks

Staying up to date

Updates. Kinoklip does not check for updates itself, and it never contacts anyone on its own. Gear Lever and AppImageUpdate read the release files on GitHub and update the AppImage when you ask them to.

Checksums. Each release also has a SHA256SUMS.txt file. To check your download, put it next to the AppImage and run:

sha256sum -c SHA256SUMS.txt

Older versions stay on the releases page.

Build it yourself. Kinoklip is GPL software. The steps are in docs/building.md on GitHub.
